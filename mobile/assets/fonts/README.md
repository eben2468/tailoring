# Bundled fonts

| Font | Files | Licence | Source |
|---|---|---|---|
| Plus Jakarta Sans (primary, from the Stitch design) | `PlusJakartaSans-{Regular,Medium,SemiBold,Bold}.ttf` | SIL OFL 1.1 (`OFL.txt`) | github.com/tokotype/PlusJakartaSans |

Fonts are bundled so text renders the same offline and on every device.
